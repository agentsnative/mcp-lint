# Disclosure Process

MCP-Lint public artifacts must not disclose unresolved third-party security
evidence.

Allowed public evidence forms:

- synthetic examples created for the rule
- already-fixed public examples with clear provenance
- abstracted patterns that do not identify a vulnerable project location
- fixtures whose `SOURCE.md` shows complete disclosure status

If disclosure status is unclear, move the evidence to private storage or rewrite
the example as synthetic before committing.
