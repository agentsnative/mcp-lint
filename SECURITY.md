# Security Policy

MCP-Lint accepts security reports for vulnerabilities in this repository or in
the linter's published package.

Please report security issues privately through GitHub's private vulnerability
reporting flow when available. If that flow is unavailable, open a minimal issue
that requests a private contact path without including exploit details.

Do not post undisclosed third-party vulnerability evidence in public issues,
pull requests, docs, specs, or fixtures. Public fixtures must be synthetic or
must include provenance showing that disclosure is complete.
